# Robot-friendly YAM gearbox STL set

Five watertight STL parts prepared for a YAM robotic assembly task.

- Overall scale: 0.90x
- Large gear: 64.3 mm maximum diameter
- Small gear: 42.7 mm maximum diameter
- Shafts: 16.2 mm diameter
- Matching bores: 21.6 mm diameter
- Gear center distance: 47.7 mm
- Sampled tooth gap: 0.20-0.26 mm through a coupled 16T/10T tooth cycle

The gears retain the robot-friendly relieved-tooth profile from the 1.00x
source set. The large gear leaves approximately 31.7 mm of total margin within
a 96 mm YAM linear-gripper opening.
