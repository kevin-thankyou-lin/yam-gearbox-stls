# Robot-friendly YAM gearbox STL set

Five watertight STL parts prepared for a YAM robotic assembly task.

- Overall scale: original 1.00x size
- Large gear: 71.5 mm maximum diameter
- Small gear: 47.5 mm maximum diameter
- Shafts: 18 mm diameter
- Matching bores: 24 mm diameter
- Gear center distance: 53 mm
- Sampled tooth gap: 0.22-0.29 mm through a coupled 16T/10T tooth cycle

The gears include 0.25 mm radial tooth relief. The large gear leaves
approximately 24.5 mm of total margin within a 96 mm YAM linear-gripper
opening.
