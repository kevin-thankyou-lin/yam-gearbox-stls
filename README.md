# Robot-friendly YAM gearbox STL set

Five watertight STL parts prepared for a YAM robotic assembly task.

- Uniform scale: 1.10x
- Large gear: 78.6 mm maximum diameter
- Small gear: 52.2 mm maximum diameter
- Shafts: 19.8 mm diameter
- Matching bores: 26.4 mm diameter
- Gear center distance: 58.3 mm
- Sampled tooth gap: 0.25-0.32 mm through a coupled 16T/10T tooth cycle

The gears include 0.25 mm radial tooth relief before the uniform scale was
applied. The large gear leaves approximately 17.4 mm of total margin within a
96 mm YAM linear-gripper opening.
